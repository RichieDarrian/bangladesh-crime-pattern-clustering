Performed exploratory data analysis and K-Means clustering on a Bangladesh crime dataset to identify distinct crime patterns based on temporal, geographical, demographic, institutional, and environmental characteristics.

Key work:

- Conducted data quality checks for missing values, duplicates, inconsistent categories, and invalid values.
- Applied feature engineering including cyclical encoding, feature aggregation, PCA, and outlier handling.
- Used KNN imputation, categorical mode imputation, StandardScaler, and RobustScaler for preprocessing.
- Analyzed feature relationships using Pearson correlation, Chi-Squared tests, Cramér's V, and eta squared.
- Tuned K-Means using the Elbow Method and Silhouette Score, selecting 3 clusters.
- Profiled the resulting clusters to identify seasonal, urban, and climate-related crime characteristics.
- Presented the analysis and findings through data visualizations and a concise presentation video.
